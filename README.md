# Gestar Digital

Observatório de gestão do Centro Obstétrico (COB).

## O que faz
- Painel de ocupação de leitos e macas
- Pendências por paciente (12/24h)
- Ficha do dia e relatório mensal exportável

## Aviso
Projeto acadêmico. Usa **apenas dados simulados**. Nunca commitar dados reais.
